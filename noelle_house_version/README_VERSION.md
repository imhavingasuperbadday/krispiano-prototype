# Noelle house version (preserved copy)

This folder is a complete, standalone copy of the prototype as it stood on
2026-08-21, *before* the root version was reworked into the black-stage
"Kris Piano Songs" scene.

It keeps everything the root version dropped:

- `room_lw_noellehouse_kitchen` background, tree, door and chairs
- the dialogue box / textbox engine and every interaction line
- `assets/mus/room_noelle_house.ogg` room music

Open `noelle_house_version/index.html` directly in a browser to run it; it has
its own `assets/` and `tools/` and shares nothing with the root version, so the
two can be worked on independently.
